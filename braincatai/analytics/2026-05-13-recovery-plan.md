## 🛠️ Step-by-step: how to unlist non-cat videos

### 📱 Mobile (приложение YT Studio)

1. Открой приложение **YT Studio** (синяя иконка с белым play)
2. Внизу нажми вкладку **"Контент"** (Content)
3. Найди видео в списке (можно сортировать по дате)
4. Нажми на видео → откроется его страница
5. Сверху справа — иконка **карандаша** (✏️) или **"Изменить"** (Edit)
6. Найди поле **"Доступ"** (Visibility) — обычно сейчас стоит "Public" 🌐
7. Нажми и выбери **"По ссылке"** (Unlisted) 🔗
8. Сверху справа — **"Сохранить"** (Save)
9. Повтори для остальных 3-х видео

### 💻 Desktop (studio.youtube.com)

1. Открой **studio.youtube.com**
2. Левое меню → **Content** (Контент)
3. Наведи курсор на нужное видео → появятся иконки в строке
4. Колонка **"Visibility"** (Доступ) — кликни на текущее значение **"Public"**
5. В выпадающем меню выбери **"Unlisted"** (По ссылке)
6. Кликни **Save**
7. Повтори для остальных 3-х видео
