# STYLE ANCHOR — единый стиль для всех кадров

Этот блок добавляется в конец **каждого** промта изображения, чтобы все кадры
видео выходили в одинаковом whiteboard / doodle-стиле.

## Основной стилевой блок (вставлять в каждый промт)

```
hand-drawn whiteboard doodle illustration, simple black ink stick figures
with round heads and minimal expressive faces, clean solid white background,
mostly black-and-white marker line art with small spots of flat color accent,
hand-lettered caption labels inside the frame, educational sketch-note /
RSA Animate explainer style, single clear concept per frame, high contrast,
16:9 horizontal composition, no photorealism, no gradients, no shading
```

## Правила консистентности

- **Соотношение сторон:** всегда 16:9 (горизонтальное).
- **Фон:** чистый белый.
- **Персонажи:** простые stick-figure человечки с круглой головой; эмоции —
  через брови, рот, позу. Один и тот же стиль человечка во всех кадрах.
- **Цвет:** по умолчанию чёрно-белая линия; цвет — только точечный акцент
  (1–2 объекта в кадре: кровать, мозг, книга, будильник и т.п.).
- **Текст в кадре:** рукописные подписи/реплики на английском (короткие,
  крупные, читаемые), повторяют значение `On-screen text` сцены.
- **Один кадр — одна мысль.** Не перегружать сцену.

## Превью (TUMB)

Для превью допускается чуть ярче: 1–2 цветовых акцента, крупная рукописная
надпись-хук, выразительное лицо человечка. То же 16:9, белый фон.
