# Переписанные заголовки

Только слабые заголовки. Сильные — оставляю как есть.

**Принципы переписи:**
- ❌ → ✅: убрать опечатки, дубли, хэштеги в самом заголовке (хэштеги идут в описание)
- Добавить **длительность** (для длинных — обязательно: «3 Hours», «8 Hours»)
- Добавить **обещание эффекта** (Sleep, Focus, Anxiety Relief, DNA Repair)
- Чередовать формулы — не превращать все заголовки в близнецов
- Длина 50-80 символов оптимально

## Как менять в YouTube Studio с телефона

1. Открой YouTube Studio (приложение или studio.youtube.com)
2. Видео → выбери нужное → ✏️ Edit
3. Title → вставь новый
4. Save (правый верхний угол)
5. Меняй по одному, не пакетно — алгоритм не любит массовые правки одновременно. **Один-два заголовка в день максимум.**
