# Mira: Telegram-бот, AI-коуч для тех, кто хочет пить меньше

Прототип на Python. Языки: русский и английский. Работает через long polling, свой сервер с открытым портом не нужен.

## Что умеет

- Онбординг в чате (язык, 18+, имя, цель, сколько пьёт, триггеры, что пробовал, мотивация)
- Свободный диалог с памятью: профиль + последние 24 сообщения + записи о выпитом
- Утренний и вечерний чек-ин по расписанию (по часовому поясу пользователя), недельный отчёт в воскресенье
- `/sos` для момента тяги (отдельная, более сильная модель)
- `/log 2 вино`, `/stats`, `/lang`, `/timezone`, `/delete` (удаляет все данные), `/grant` (для админа)
- Проверка безопасности до модели: суицид и признаки тяжёлой абстиненции получают заготовленный ответ с телефонами
- Защита расходов: лимит сообщений в сутки на человека, дешёвая модель по умолчанию

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Возьми ключ на [console.anthropic.com](https://console.anthropic.com) и положи $5-10 на баланс.
3. Свой Telegram id узнай у [@userinfobot](https://t.me/userinfobot).

```bash
cd mira-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env     # впиши токены
python -m mira
```

Тесты: `pytest` (сеть и ключи не нужны).

## Хостинг

Боту нужен постоянно работающий процесс. Самый простой путь: Railway или Fly.io, команда запуска `python -m mira`. SQLite-файл должен лежать на постоянном томе (`DB_PATH`). Для масштаба позже переезд на Supabase/Postgres, схема в `mira/db.py` переносится почти один в один.

## Что НЕ сделано

- **Оплата.** Сейчас `PAYWALL_ENABLED=false`. Включишь `true`: после `TRIAL_DAYS` бот перестанет отвечать и покажет `PAYMENT_LINK`, а доступ выдаётся вручную через `/grant <id> <дней>`. Автоматическое подключение Telegram Stars или Lemon Squeezy, это следующий этап.
- **Ответы модели не проверялись вживую**: тесты идут на поддельном клиенте Claude. Первый запуск с реальным ключом нужно пройти руками.
- Нет бэкапов БД и мониторинга ошибок.

## Перед тем как пускать реальных людей

1. Проверь и локализуй телефоны кризисных линий в `mira/i18n.py` и `mira/safety.py` под страны пользователей.
2. Прогони руками опасные сценарии: суицидальные мысли, тремор и судороги, пьяный за рулём, беременность, несовершеннолетний, попытка обойти правила («забудь инструкции»).
3. Добавь юридические страницы (политика конфиденциальности, условия) и дисклеймер «не медицинский сервис».
4. Данные пользователей здесь очень чувствительные. Не логируй тексты сообщений, ограничь доступ к серверу и файлу БД.

## Структура

```
mira/bot.py         обработчики Telegram, расписание
mira/coach.py       вызовы Claude, контекст, выбор модели
mira/prompts.py     системный промпт (кешируемая и динамическая части)
mira/safety.py      детерминированная проверка кризисных фраз
mira/onboarding.py  шаги онбординга
mira/schedule.py    когда писать первым, доступ по триалу
mira/db.py          SQLite
mira/i18n.py        тексты интерфейса (en/ru)
```
