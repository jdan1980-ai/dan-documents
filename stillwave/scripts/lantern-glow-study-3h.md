## 6. 🛠️ ffmpeg encode command (loop the 8-sec video to 3H + audio)

```bash
ffmpeg -stream_loop -1 -i lantern-glow-study-3h-loop.mp4 -i lantern-glow-study-3h.mp3 \
  -c:v libx264 -preset medium -crf 23 -pix_fmt yuv420p \
  -c:a aac -b:a 192k -shortest -t 10800 lantern-glow-study-3h.mp4
```
