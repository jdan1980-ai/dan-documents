# Видео 3 — All 7 Chakras Healing While You Sleep (3 часа)

**Опубликовано 11.11.2026** под основным названием.

Картинка: `visuals/base_side_sleep.jpg` (спит на боку, цветная лента из 7 цветов чакр).
Обложка: `visuals/thumbs/thumb_all_7_chakras.jpg` — «ALL 7 CHAKRAS / HEAL WHILE YOU SLEEP».
Луп 8 с: `make_loop.py ... --ribbon ...` (команда в `sevenlights/CLAUDE.md`).
Плейлисты: A (все ночи), D (чакры).

Звук: 6 новых треков Musicful (третий альбом), все в строе 440 Гц. Порядок подобран по тональностям:
«528 Hz Drift (4)», «Miracle Drift», «Miracle Drift (1)» (до-диез мажор) → «528 Hz Drift (3)» (соль-диез мажор) →
«528 Hz Drift Mashup (1)», «528 Hz Drift Mashup» (фа мажор / ре минор), затем круг повторяется.
Повторов с видео 2 нет: максимальное сходство с треками видео 2 — 0.82 (копия дала бы 0.95+).
```
pwsh -File .\make_long_track.ps1 -In "528 Hz Drift (4).mp3,Miracle Drift.mp3,Miracle Drift (1).mp3,528 Hz Drift (3).mp3,528 Hz Drift (Mashup) (1).mp3,528 Hz Drift (Mashup).mp3" -TrimStart 8 -TrimEnd 6 -Hours 3 -Out SevenLights3_3h.flac
```

Отличие от видео 1–2: в названии и на обложке нет частоты в Hz — главная тема «7 чакр», а не 528.
Описание не называет частоты музыки, поэтому подходит для любой сборки (Musicful или генератор).
Если длительность не 3 часа — поправить «3 hours / 3 часа» во всех языках.
