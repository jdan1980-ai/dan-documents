## Общие принципы, по которым они написаны

1. **3-4 короткие строки** — читается одним взглядом на мобильнике
2. **Конкретный ритуал** под тему видео (свеча для огня, вода для DNA Repair, дыхание 4/6 для ночи)
3. **Японское слово** с переводом — добавляет аутентичности и подсказывает алгоритму ниши
4. **Один открытый вопрос** в конце — мягко тянет на комментарий, не насилует «like and subscribe»
5. **Без призыва подписаться** — это работает лучше для медитативной ниши, где аудитория не любит давление
6. **Эмодзи дозированно** — 1-2 на закреп, в тон видео

## Что ещё можно сделать к этим закрепам

- **Описание видео** — могу написать SEO-описания (200-500 слов) с ключевиками для каждого
- **Tags** — список тегов на каждое видео для YouTube Studio
- **End screen / cards** идеи — какие видео из канала рекомендовать в конце
- **Заголовки v2** — переписать слабые заголовки под формулы конкурентов
