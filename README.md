# Мой день

Планировщик дня, который строит расписание под ваш хронотип (жаворонок / голубь / сова),
вашу роль (студент, офисный или удалённый сотрудник, фрилансер, родитель, предприниматель,
спортсмен) и список приоритетов на сегодня.

## Как это работает

1. Вы отвечаете на три коротких вопроса: ритм, роль, приоритеты и время подъёма/отбоя.
2. Движок (`src/lib/schedule.ts`) строит скелет дня — рутины, приёмы пищи, обязательные
   блоки роли — а оставшееся свободное время распределяет между выбранными приоритетами,
   стараясь подобрать под каждый задачу подходящий уровень энергии по кривой хронотипа
   (`src/data/chronotypes.ts`).
3. Готовый план отображается таймлайном с отметками выполнения, который сохраняется в
   `localStorage` и переживает перезагрузку страницы.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

## Стек

Vite + React + TypeScript + Tailwind CSS.
