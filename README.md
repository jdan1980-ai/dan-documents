# Whiteboard-видео: автоматизация сценария и раскадровки

Движок для конвейерного производства doodle / whiteboard-видео
(стиль рисованного скетч-объяснения, как RSA Animate / Doodly).

## Как это работает

1. **Ты задаёшь** тему и длительность в минутах.
   > Пример: «Тема: почему телефон убивает концентрацию. 3 минуты.»
2. **Claude выдаёт** готовый сценарий, разбитый по кадрам. Для каждого кадра:
   - номер сцены;
   - текст, который рисуется прямо в кадре (on-screen text);
   - промт для генерации картинки в Google AI Studio (Gemini/Imagen) — в едином стиле;
   - текст для озвучки (narration).
   - отдельно — промт для превью (TUMB).
3. **Ты** скачиваешь пакет картинок из AI Studio, генеришь озвучку под каждый
   кадр и монтируешь в CapCut.

Результат каждого видео сохраняется в Google Drive в папку с названием темы.

## Сколько кадров на минуту

Темп закадрового текста ≈ **140 слов/минуту**. Один кадр держится в среднем
**~10 секунд** (≈ 23 слова). Отсюда правило по умолчанию:

| Длительность | Кадров (≈) |
|--------------|------------|
| 1 мин        | 6          |
| 2 мин        | 12         |
| 3 мин        | 18         |
| 5 мин        | 30         |

**Формула:** `кадров ≈ минуты × 6` (диапазон 5–7 кадров/мин).
Если хочешь плотнее/реже — скажи число кадров явно.

## Стиль (фиксированный)

Чтобы все кадры выходили в одном стиле, к каждому промту добавляется
единый блок — см. [`STYLE_ANCHOR.md`](STYLE_ANCHOR.md).

## Формат выдачи

Полный шаблон одного видео — в [`TEMPLATE.md`](TEMPLATE.md).

## Соглашения по файлам (под текущий процесс)

- Картинки кадров: `1.jpeg`, `2.jpeg`, … по порядку сцен.
- Превью: `TUMB.jpeg`.
- Папка темы в Google Drive называется по теме видео.
